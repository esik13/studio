# Strelnikov Studio — версия для GitHub Pages

Это статическая версия сайта: она работает на GitHub Pages без Node.js, VPS и отдельного хостинга.

## Публикация

1. Создайте на GitHub новый публичный репозиторий, например `strelnikov-studio`.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html` и папку `assets`.
3. Откройте репозиторий → **Settings → Pages**.
4. В разделе **Build and deployment** выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через минуту GitHub покажет адрес сайта в разделе Pages.

Важно: загружайте именно `index.html` и `assets` в корень репозитория, а не саму папку `strelnikov-studio-github`.

## Что работает

- Все разделы сайта и навигация по страницам.
- Адаптивная вёрстка, анимации и галерея.
- Форма записи в демонстрационном режиме.
- Главное фото заменено на изображение, предоставленное владельцем проекта.

## Ограничения GitHub Pages

GitHub Pages размещает только статические файлы. Поэтому в этой версии форма записи показывает демонстрационный сценарий: заявки не отправляются владельцу и не сохраняются на сервере; свободные слоты и расписание не проверяются в реальном времени. Админка и серверная часть в публикацию не включены.

Для настоящей онлайн-записи, хранения заявок, уведомлений и защищённой админки понадобится отдельный backend или внешний сервис форм/бронирования.
